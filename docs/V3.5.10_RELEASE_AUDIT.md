## 6. Parser Defensive Fix Summary

V3.5.10 included parser robustness improvements for unexpected LLM JSON structures:

* Improved handling of malformed JSON from grouped mode responses
* Added salvage logic for partial agent outputs
* Parse errors in grouped mode did not affect separate mode stability
* Separate mode parse error (MaintainabilityAgent) is a pre-existing V3.5.9 issue, non-blocking

The benchmark showed a Chinese label (`代码坏味道`) in the CodeSmellAgent output. Investigation confirmed:

* The Chinese report was functionally correct
* **Result: False positive** ✅
