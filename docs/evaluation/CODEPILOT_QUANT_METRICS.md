# CodePilot Quant Metrics

CodePilot V3.7 quant metrics are generated by `scripts/metrics/run_quant_metrics.py`.
The script is intentionally outside the product path and only reads existing parser,
indexer, prompt, Mock LLM, Real LLM, and report generation behavior.

## Metric Scope

- Noise reduction uses `git ls-files` as the primary denominator and the existing sandbox/file filter as the eligible-file numerator.
- Token compression compares raw source text for analyzed files with `PromptRenderer` structured context for the same analyzed scope.
- Code understanding metrics reuse parser/indexer summaries and Python `ast.parse` checks.
- Agent quality metrics are computed separately for Mock, Real LLM, and the one-repo direct LLM baseline.
- Quality gates are written to `reports/quant_metrics_v3_7/raw_logs/`.

## Real LLM And Baseline

Real LLM mode uses the existing provider resolution order from CodePilot settings.
API keys are never printed in full. If Real LLM fails after retry, the run records
the failure and continues. Baseline uses the same OpenAI-compatible request shape
but swaps the input from structured CodePilot context to raw source snippets from
the same analyzed file scope.

The baseline is a small-repo qualitative comparison only. It should not be described
as a large-scale controlled experiment.

## Reproduction

```powershell
python scripts/metrics/run_quant_metrics.py --benchmark evaluation/datasets/repos.json --mode both --max-repos 3 --output reports/quant_metrics_v3_7
git diff --check
python -m pytest tests/metrics -q
python -m pytest tests/ -q
ruff check .
python scripts/audit_harness.py
```

If Real LLM is unavailable, run these narrower commands and keep the recorded failures:

```powershell
python scripts/metrics/run_quant_metrics.py --benchmark evaluation/datasets/repos.json --mode real --max-repos 1 --output reports/quant_metrics_v3_7
python scripts/metrics/run_quant_metrics.py --benchmark evaluation/datasets/repos.json --mode baseline --max-repos 1 --output reports/quant_metrics_v3_7
```
