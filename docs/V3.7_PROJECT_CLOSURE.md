## Version Summary

CodePilot V3.7 is a stable demo release that finalizes the multi-agent code review pipeline with global bilingual support, evidence-backed findings, and a polished resume-ready presentation. The project is frozen — no new features will be added beyond this point.

---

## Completed Features

### Repository Intelligence
- tree-sitter parsing for Python, JavaScript, and TypeScript
- AST-based context extraction with fallback heuristics
- Structured context building (no raw source code sent to LLM)

### Multi-Agent Review Pipeline
- Four parallel specialist agents: Architecture, CodeSmell, Maintainability, Refactor
- Each agent returns structured findings with severity, category, and evidence links
- Report composer merges agent outputs into a unified four-section report

### Evidence System
- Every finding links to `[E1]`/`[E2]` evidence references with file paths and line numbers
- `EvidenceDisplayMap` maps raw `ev_*` IDs to human-readable `[E{N}]` format
- Raw evidence IDs are never exposed in UI, reports, or exports

### Bilingual Output
- Global zh/en language switch with `localStorage` persistence
- All UI labels, reports, findings, error messages, and exports follow the active language
- Mock mode uses `MockTranslator` for deterministic Chinese output
- MiMo mode uses LLM-based translation with fallback to mock when unavailable

### Report Export
- One-click Markdown export via `GET /api/reviews/{task_id}/export`
- Export respects current language (en or zh)
- Content-Disposition header provides proper filename
- Evidence appendix is self-contained (no snippet dependencies)

### Error Handling
- Structured `APIError` responses with error code and detail
- Localized error messages for stale reviews, export failures, auth errors, timeouts
- Secret sanitization in error messages
- Frontend maps error codes to user-friendly localized messages

### Mock Demo Mode
- Deterministic `MockLLMClient` returns pre-built bilingual findings
- No API key or network required
- Stable path for demos, resume review, and development

### CLI Workflows
- `review`, `ci`, and `diff` commands for scripted usage
- JSON output support for CI integration

## Architecture Summary

```
GitHub URL → Clone → Parse (tree-sitter) → Build Context
                                                    ↓
                                        Multi-Agent Review
                                        ├── Architecture Agent
                                        ├── CodeSmell Agent
                                        ├── Maintainability Agent
                                        └── Refactor Agent
                                                    ↓
                                        Structured Findings + Evidence Map
                                                    ↓
                                        Report Composer → [E1]/[E2] References
                                                    ↓
                                        Display (Next.js UI) + Export (Markdown)
```

**Backend:** FastAPI, Python 3.11, SQLite WAL, ThreadPoolExecutor
**Frontend:** Next.js 15.5, React 19, TypeScript 5.7, Tailwind CSS 3.4
**Parser:** tree-sitter with AST fallback
**LLM:** OpenAI-compatible chat completions or deterministic mock mode

## Known Limitations

1. **MiMo Chinese output** — may still have occasional unnatural wording in zh reports. Mock mode zh is deterministic and stable. MiMo zh quality depends on the model and prompt.

2. **Ephemeral storage** — free Render/tmp SQLite may lose review history after restart. This is expected for demo deployments. Persistent storage requires a paid hosting tier or external database.

3. **Real LLM dependency** — MiMo/OpenAI mode requires a valid API key, network access, and provider availability. Output quality varies by model. No fallback to mock if the provider fails.

4. **Language depth** — analysis is strongest for Python. JavaScript and TypeScript support is functional but less deep. No support for Go, Rust, Java, or other languages yet.

5. **No production workflow** — GitHub OAuth, PR bot, MCP integration, vector DB, and LangGraph workflows are not implemented. These are future ideas, not planned work.

6. **Static analysis only** — CodePilot does not execute repository code. It uses heuristic and AST-based analysis. Some findings may be false positives.

7. **File limits** — analyzes at most 300 supported source files, skips files over 200KB. Large monorepos may exceed these limits.

8. **Grouped mode experimental** — grouped agent review mode exists behind a flag but is not production-ready.

## What Was Intentionally Stopped

- **No new features** — V3.7 is a freeze. The pipeline, evidence system, bilingual output, and export are complete.
- **No Chinese edge-case optimization** — mock mode zh is stable; MiMo zh has known limitations that are acceptable for demo.
- **No LLM/provider changes** — the mock/real toggle works. Provider-specific tuning is out of scope.
- **No UI redesign** — the current Next.js UI is functional and resume-ready.
- **No DB/storage changes** — SQLite is sufficient for demo. Migration to Postgres or external storage is a future idea.
- **No dependency additions** — the current stack is stable and well-tested.
