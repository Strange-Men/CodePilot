# V3.5.12 Final Chinese Quality Cleanup

> Date: 2026-06-17
> Status: Complete
> Branch: master

## Scope

This final V3.5.12 cleanup closes the remaining English leakage in Chinese
reports, exports, and finding display fields. It does not change UI polish,
grouped mode, provider/LLM behavior, storage, database schema, secrets, or
deployment behavior.

## Root Cause

The V3.5.12 Chinese quality guard already handled common finding prose and raw
evidence IDs, but repository metadata still came from English canonical report
templates and compact count summaries. Those fragments were short enough to
avoid natural-language leak detection and were not covered by the original
phrase table.

Examples included:

- `83 Python source files`
- `83 of 83 supported source files`
- `Entry points`, `Core modules`, `Dependency hubs`
- `completed`, `validated`, `running`, `failed`
- `2 medium, 2 low`
- `validated symbols`, `no findings`, `n/a`

## Fix

`backend/reviewers/zh_quality.py` now uses one shared non-code normalization
path for both individual display fields and Markdown reports.

The guard now:

- Preserves fenced code blocks unchanged.
- Preserves inline code spans unchanged.
- Preserves file paths, commands, evidence refs, and allowed tech tokens.
- Replaces raw `ev_*` IDs in user-facing zh text with `[E?]` when no display
  map has already converted them.
- Normalizes metadata labels, status values, severity values, and mixed count
  phrases.

## Added Rules

| English | Chinese |
|---------|---------|
| Python source files | Python 源文件 |
| source files | 源文件 |
| supported source files | 支持的源文件 |
| analyzed files | 已分析文件 |
| skipped files | 已跳过文件 |
| Entry points | 入口文件 |
| Core modules | 核心模块 |
| Dependency hubs | 依赖枢纽 |
| Cycle group | 循环依赖组 |
| completed | 已完成 |
| validated | 已验证 |
| running | 运行中 |
| failed | 失败 |
| medium | 中 |
| low | 低 |
| high | 高 |
| info | 信息 |
| validated symbols | 已验证符号 |
| no findings | 暂未发现明确问题 |
| n/a | 不适用 |

Mixed phrase normalization:

- `83 Python source files` -> `83 个 Python 源文件`
- `analyzed 83 and skipped 0` -> `已分析 83 个，已跳过 0 个`
- `83 of 83 supported source files` -> `已分析 83 / 83 个支持的源文件`
- `4 medium` -> `4 个中风险`
- `2 medium, 2 low` -> `2 个中风险，2 个低风险`
