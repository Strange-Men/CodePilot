## 7. Remaining Warnings

1. **Language switch requires network roundtrip:** The zh report is fetched from the backend on language switch. The translation is deterministic (no LLM), but the user perceives a brief network delay. This is a UX consideration, not a release blocker.

2. **Benchmark runtime variance:** Real MiMo benchmark took 280.6s vs ~121s in prior runs. This is API load variance, not a code regression.

3. **One invalid attempt in CodeSmellAgent:** During the benchmark, CodeSmellAgent had 1 invalid attempt (validation_tests field was None). The agent retried successfully and produced 2 valid findings.
