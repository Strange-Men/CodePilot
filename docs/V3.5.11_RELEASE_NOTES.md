# CodePilot V3.5.11 Release Notes

**Release Date:** 2026-06-16
**Tag:** v3.5.11
**Type:** Hotfix

---

## Summary

V3.5.11 fixes three bugs discovered during V3.5.10 production validation:

1. **All-agent failure marked as completed** — When all agents failed, the review status was incorrectly set to `completed` instead of `failed`. Fixed with proper error logging.

2. **MiMo provider used wrong API key** — The MiMo LLM client was incorrectly requiring `OPENAI_API_KEY` instead of `MIMO_API_KEY`. Fixed to use the correct provider-specific key.

3. **Frontend LLM mode not honored in execution** — The most critical fix. When a user selected "Mock" in the UI, the backend runner still used the default client (which could be MiMo in production). Fixed by building the LLM client per-task based on the selected `llm_mode`.

---

## Changes

### Fixes

- **`a924b9e`** — Fix all-agent failure being marked as completed; add per-agent error logging
- **`20311b3`** — Fix MiMo provider to use `MIMO_API_KEY` instead of `OPENAI_API_KEY`
- **`fd2e1ff`** — Fix `runner._run()` to call `build_llm_client_for_mode(settings, llm_mode)` per task

### Behavior After Fix

| Mode | Before V3.5.11 | After V3.5.11 |
|------|----------------|---------------|
| Mock selected | Ran real MiMo in production | Uses MockLLMClient, no API calls |
| MiMo selected | Required OPENAI_API_KEY | Uses MIMO_API_KEY only |
| All agents fail | Status = completed | Status = failed |

## Known Limitations

- MiMo API endpoint (`token-plan-cn.xiaomimimo.com`) is not reachable from US-based cloud infrastructure (Render). MiMo production reviews require China-region deployment.
- Grouped agent mode remains experimental and is not the default.

---

## Upgrade Notes

No breaking changes. No database migration required. No new environment variables.

If upgrading from V3.5.10:
- Ensure `MIMO_API_KEY` is set (not `OPENAI_API_KEY`) for MiMo mode
- `USE_MOCK_LLM=false` and `ENABLE_REAL_LLM=true` are required for real LLM reviews
