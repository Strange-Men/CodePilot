# V3.6 UI Polish

> Date: 2026-06-17
> Status: Complete
> Branch: master

## Scope

V3.6 polishes the existing CodePilot review workspace into a clearer product
surface without changing backend behavior, providers, grouped mode, storage,
secrets, or deployment configuration.

The work stays on the V3.5.12 product contract: mock mode remains the stable
demo path, MiMo remains optional, reports keep E1/E2 evidence refs, and Chinese
report text remains a backend quality contract.

## Product Changes

### Workspace Shell

- Reworked the header into a compact cockpit surface with a consistent brand
  mark, status badge, language toggle, and theme toggle.
- Added reusable status badge styling for idle, queued, running, completed,
  failed, skipped, and warning states.
- Categorized common review errors into user-facing messages for stale review,
  provider authentication, provider network, provider rate limit, start failure,
  delete failure, and generic fallback cases.

### Sidebar

- Replaced the LLM mode select with a segmented control for Mock and MiMo.
- Added clearer current-status presentation and an export hint tied to
  self-contained Markdown reports.
- Kept the existing export behavior and backend contract unchanged.

### Review Reading

- Improved Markdown readability with table, code, blockquote, link, and heading
  styling.
- Linked visible report references such as `[E1]` to the Evidence Appendix while
  preserving fenced code blocks and inline code.
- Numbered report outline and section headings for faster scanning.

### Agents And Findings

- Added a compact progress bar to the agent timeline.
- Standardized agent and review statuses through the shared status badge.
- Tightened finding cards and evidence chips without changing structured review
  data.

### Evidence

- Added a frontend evidence display helper that shows stable user-facing refs
  such as `[E1]` and hides raw `ev_*` IDs in the UI.
- Kept file paths, symbols, line numbers, and evidence snippets visible.
- Verified the report and evidence tabs expose no raw `ev_*` IDs in the browser.

## Tests
