## 6. Finding: Model Label Bug (Cosmetic)

The orchestrator logs `provider=openai model=gpt-4o-mini` even when using MiMo.

**Root cause:** `pipeline.py` line 252 passes `self.settings.openai_model` (default `gpt-4o-mini`) as `token_model` to the ReportGenerator, which passes it to agents. The actual HTTP requests correctly go to MiMo with `mimo-v2.5-pro`.

**Impact:** Logging only. No effect on actual LLM calls.

**Fix location:** `backend/tasks/pipeline.py` line 252 — should pass `self.settings.mimo_model_name` when in MiMo mode, or derive from the LLM client.
