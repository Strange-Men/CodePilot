# V3.7 Step 2 — Global Language Switch System

## Design Decision

### UI i18n + Backend Report Lang

CodePilot uses a **dual-layer localization architecture**:

1. **Frontend UI labels**: Dictionary-based i18n in `frontend/lib/i18n.ts` with `t(language, key)` function. All UI text (buttons, tabs, status, errors, empty states) is translated via lookup tables.

2. **Backend report content**: The backend receives `?lang=zh` or `?lang=en` query parameters and returns localized report markdown, findings prose, and evidence references. The backend handles:
   - Report section headings and structural text
   - Finding title/description/recommendation/impact/caveat prose
   - Evidence display mapping (ev_* → [E1]/[E2])

### Why DOM Auto-Translation is Not Used

DOM auto-translation (e.g., Google Translate) is explicitly avoided because:

1. **Unpredictable quality**: Machine translation of technical code review content produces unreliable results
2. **Breaks interactive elements**: Auto-translation can corrupt data attributes, code references, and evidence IDs
3. **No control over scope**: Cannot exclude code paths, commands, [E1]/[E2] markers from translation
4. **Inconsistent state**: DOM translation doesn't sync with API lang parameter, causing mismatched UI
5. **Performance**: DOM mutation for translation adds unnecessary rendering overhead

Instead, all translations are pre-computed: UI labels via dictionaries, report content via backend rendering.

### Language Parameter Behavior

- `lang=en` (default): No query param sent, English report returned
- `lang=zh`: `?lang=zh` appended, Chinese report returned
- Backend normalizes: `"zh"`, `"zh-CN"`, `"zh_cn"` → `"zh"`; everything else → `"en"`

## localStorage Behavior

**Key**: `codepilot.lang`

**Values**: `"zh"` | `"en"`

**Default detection**:
1. Check localStorage for stored value
2. If stored value is valid (`"zh"` or `"en"`), use it
3. Otherwise, detect browser language:
   - `navigator.language` starts with `"zh"` → `"zh"`
   - All others → `"en"`

**Persistence**:
- Written on every language toggle
- Survives page refresh and browser restart
- Gracefully handles localStorage unavailability (SSR, private browsing)
