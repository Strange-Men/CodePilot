# CodePilot V3.7 Release Notes

**Release Date:** 2026-06-18
**Branch:** master
**Status:** Stable

---

## Highlights

- **Global Language Switch** — zh/en toggle in the UI that switches all reports, findings, labels, and error messages. Choice persists in localStorage across refreshes.
- **Chinese Report Quality** — rebuilt presentation pipeline with English leakage blocking, MiMo fallback, and confidence-aware regex fixes.
- **Evidence Display System** — raw `ev_*` IDs are replaced with `[E1]`/`[E2]` references throughout all views and exports.
- **Stale/Error Handling** — friendly, localized error messages for stale reviews, export failures, auth errors, and timeouts.
- **CI Green** — 995 backend tests + 104 frontend tests passing. Harness audit clean.

## Known Limitations

1. **MiMo Chinese output** — occasional unnatural wording in zh reports when using real LLM mode. Mock mode zh is stable.
2. **Ephemeral storage** — free Render/tmp SQLite loses history after restart.
3. **Real LLM dependency** — requires valid API key, network, and provider availability.
4. **Language depth** — Python analysis is strongest; JS/TS functional but less deep.
5. **No production workflow** — no GitHub OAuth, PR bot, MCP, vector DB, or LangGraph yet.
6. **Static analysis only** — does not execute code; some findings may be false positives.
7. **File limits** — max 300 files, skips files over 200KB.
