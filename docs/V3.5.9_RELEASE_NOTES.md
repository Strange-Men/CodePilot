# CodePilot V3.5.9 Release Notes

**Version:** V3.5.9
**Release status:** stable
**Release date:** 2026-06-16

## Summary

V3.5.9 focuses on real LLM integration quality, bilingual output stability, and actionable Chinese report generation. The release delivers measurable improvements in finding usefulness, CodeSmellAgent reliability, and native Chinese report polish.

## Main Improvements

- **Real MiMo performance instrumentation** — added end-to-end timing for real LLM calls, enabling benchmark tracking across releases.
- **concurrency=4 validation** — verified multi-agent parallel execution against real MiMo provider, confirming stable behavior at the configured concurrency level.
- **One-pass bilingual output stability** — agents produce both English and Chinese display fields in a single LLM call, eliminating post-completion translation overhead.
- **CodeSmellAgent structured output fix** — resolved parse failures that caused empty or weak findings from the code smell analysis agent.
- **Native Chinese report polish** — Chinese sections now use natural phrasing, actionable language, and domain-appropriate terminology.
- **P1/P2/P3 priority recommendation layer** — findings are classified into priority tiers with clear guidance on what to fix first.
- **Chinese report/export no post-completion LLM translation** — switching to Chinese view and exporting Markdown remain instant after review completion.
- **CI and audit_harness fully green** — all quality gates pass consistently.

## Quality Improvements

- Findings increased from weak/empty agent outputs to useful multi-agent findings across architecture, code smells, security, and performance dimensions.
- CodeSmellAgent parse issue fixed — structured findings now surface correctly.
- Bare English label leakage in Chinese report sections fixed.
- Chinese report is more native, actionable, and aligned with Chinese developer expectations.

## Known Limitations

- Runtime still depends on MiMo provider latency; no offline fast path for real LLM mode.
- 2-call grouped agents (batch review strategy) not yet implemented.
- Chinese output quality can continue improving with further prompt iteration.
- Report evidence explanation remains deterministic and conservative by design.

## Recommended Next Steps (V3.5.10 / V3.6)

- Optional 2-call grouped agents for batch review efficiency.
- Deeper evidence explanation with source-line references.
- Chinese-primary output strategy evaluation.
- Product UX polish (loading states, progress indicators, export options).
